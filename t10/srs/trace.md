# Трассировка: сортировка выбором, вставками, бинарный поиск

## 1. Сортировка выбором, a = {5, 2, 9, 1, 7}

Всего проходов n-1 = 4. На проходе i сравнений n-1-i.

- Проход i=0: минимум 1, индекс 3. Обмен a[0] и a[3].
  Массив: {1, 2, 9, 5, 7}. Сравнений: 4.
- Проход i=1: в части {2, 9, 5, 7} минимум 2, индекс 1. Обмен с самим собой.
  Массив: {1, 2, 9, 5, 7}. Сравнений: 3.
- Проход i=2: в части {9, 5, 7} минимум 5, индекс 3. Обмен a[2] и a[3].
  Массив: {1, 2, 5, 9, 7}. Сравнений: 2.
- Проход i=3: в части {9, 7} минимум 7, индекс 4. Обмен a[3] и a[4].
  Массив: {1, 2, 5, 7, 9}. Сравнений: 1.

Общее число сравнений: 4 + 3 + 2 + 1 = 10.

## 2. Сортировка вставками, a = {4, 3, 2, 1}

- i=1: key=3. Сдвигов: 1 (4 сдвигается вправо). Массив: {3, 4, 2, 1}.
- i=2: key=2. Сдвигов: 2 (4 и 3). Массив: {2, 3, 4, 1}.
- i=3: key=1. Сдвигов: 3 (4, 3 и 2). Массив: {1, 2, 3, 4}.

Всего сдвигов: 1 + 2 + 3 = 6. Это равно числу инверсий в исходном массиве.

На уже отсортированном массиве из 4 элементов для каждого i от 1 до 3 выполняется одно сравнение элементов: a[j] > key ложно, сдвигов нет. Итого 3 сравнения (n-1). Это лучший случай, O(n).

## 3. Бинарный поиск в {1, 3, 5, 7, 9, 11, 13}

Индексы 0..6.

### x = 7

- Шаг 1: lo=0, hi=6, mid=3, a[3]=7. Равно x, найдено. Ответ: индекс 3.

### x = 6

- Шаг 1: lo=0, hi=6, mid=3, a[3]=7. 7 > 6, поэтому hi = 2.
- Шаг 2: lo=0, hi=2, mid=1, a[1]=3. 3 < 6, поэтому lo = 2.
- Шаг 3: lo=2, hi=2, mid=2, a[2]=5. 5 < 6, поэтому lo = 3.
- Шаг 4: lo=3, hi=2. Так как lo > hi, цикл заканчивается.

Поиск заканчивается без совпадения, элемента 6 в массиве нет. Возвращается -1

LowerBound(6) возвращает 3: это первый индекс, где a[i] >= 6, то есть значение 7.
