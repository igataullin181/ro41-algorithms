# t02 СРСП: количество и сумма цифр числа

Дано целое число n (не меньше 0). Программа выводит, сколько в нём цифр и чему равна их сумма.

## Файлы

- `pseudocode.md` — псевдокод.
- `flowchart.png` — схема алгоритма (ГОСТ 19.701-90).
- `trace.md` — ручная трассировка для n = 472 и n = 0.
- `Program.cs` — консольная программа на C#.
- `srsp.csproj` — файл проекта.

## Почему цикл «повторять … пока»

У числа 0 одна цифра, поэтому тело цикла должно выполниться хотя бы один раз. Обычный цикл «пока n > 0» для 0 не выполнится и даст 0 цифр. Поэтому используется do-while.

## Запуск

```
dotnet run
```

## Проверка

| Ввод  | Ожидаемый результат                 |
|-------|-------------------------------------|
| 472   | Цифр: 3, сумма цифр: 13             |
| 0     | Цифр: 1, сумма цифр: 0              |
| 7     | Цифр: 1, сумма цифр: 7              |
| 1000  | Цифр: 4, сумма цифр: 1              |
| -3    | Ошибка: нужно целое число не меньше 0. |
| abc   | Ошибка: нужно целое число не меньше 0. |
