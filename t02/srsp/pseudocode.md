# t02 СРСП: количество и сумма цифр числа

Дано: целое число n, n ≥ 0.
Нужно: количество цифр в n и сумма этих цифр.

## Псевдокод

```
НАЧАЛО
    ВВОД n
    ЕСЛИ n не целое ИЛИ n < 0 ТО
        ВЫВОД "Ошибка: нужно целое число не меньше 0"
    ИНАЧЕ
        sum ← 0
        count ← 0
        ПОВТОРЯТЬ
            digit ← n mod 10
            sum ← sum + digit
            count ← count + 1
            n ← n div 10
        ПОКА n > 0
        ВЫВОД count, sum
    КОНЕЦ ЕСЛИ
КОНЕЦ
```

Почему цикл «ПОВТОРЯТЬ … ПОКА»: тело выполняется хотя бы один раз, поэтому для n = 0 получается одна цифра (0), а сумма 0.
