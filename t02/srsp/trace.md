# Ручная трассировка

Строка после итерации показывает значения после выполнения тела цикла.

## n = 472

| Итерация | n (до итерации) | сумма | количество | условие цикла (n > 0) |
|---|---|---|---|---|
| начало | 472 | 0 | 0 | — |
| 1 | 472 → 47 | 2 | 1 | да |
| 2 | 47 → 4 | 9 | 2 | да |
| 3 | 4 → 0 | 13 | 3 | нет, выход |

Результат: цифр 3, сумма 13.

## n = 0

| Итерация | n (до итерации) | сумма | количество | условие цикла (n > 0) |
|---|---|---|---|---|
| начало | 0 | 0 | 0 | — |
| 1 | 0 → 0 | 0 | 1 | нет, выход |

Результат: цифр 1, сумма 0. Цикл «пока» здесь дал бы 0 цифр, поэтому используется цикл «повторять … пока».
