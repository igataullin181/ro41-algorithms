# Трассировка работы с массивом a = {4, 1, 7, 3, 9}

## 1. Циклический сдвиг влево на одну позицию

Значение `a[0]` сохраняем в буфер, затем каждый элемент берём из следующего, а последний заполняем буфером.

```java
int buf = a[0];
for (int i = 0; i < n - 1; i++)
    a[i] = a[i + 1];
a[n - 1] = buf;
```

| Шаг | i | Состояние массива после шага |
|-----|---|------------------------------|
| 0   | —   | buf = 4, a = {4, 1, 7, 3, 9} |
| 1   | 0   | a[0] = a[1] = 1, a = {1, 1, 7, 3, 9} |
| 2   | 1   | a[1] = a[2] = 7, a = {1, 7, 7, 3, 9} |
| 3   | 2   | a[2] = a[3] = 3, a = {1, 7, 3, 3, 9} |
| 4   | 3   | a[3] = a[4] = 9, a = {1, 7, 3, 9, 9} |
| 5   | 4   | a[4] = buf = 4, a = **{1, 7, 3, 9, 4}** |

Результат: {1, 7, 3, 9, 4}. Каждый элемент сдвинулся на одну позицию влево, первый оказался в конце.

## 2. Разворот массива на месте

Меняем местами `a[i]` и `a[n - 1 - i]`:

```java
for (int i = 0; i < n / 2; i++) {
    int tmp = a[i];
    a[i] = a[n - 1 - i];
    a[n - 1 - i] = tmp;
}
```

| Шаг | i | Пара обмена | Состояние массива после шага |
|-----|---|-------------|------------------------------|
| 0   | —   | —           | {4, 1, 7, 3, 9} |
| 1   | 0   | a[0] ↔ a[4] | {9, 1, 7, 3, 4} |
| 2   | 1   | a[1] ↔ a[3] | **{9, 3, 7, 1, 4}** |

**Сколько обменов:** 2 (при n = 5, n / 2 = 2).

**Почему цикл идёт только до n / 2:** каждый обмен обрабатывает сразу пару элементов, стоящих симметрично относительно центра. Для n = 5 это пары (0, 4) и (1, 3). Центральный элемент `a[2] = 7` при развороте остаётся на месте, поэтому отдельно его менять не нужно. Если продолжить цикл дальше n / 2, каждая пара будет менять местами второй раз и вернётся в исходное состояние: разворот «отменится». Для чётного n, например n = 4, цикл до n / 2 = 2 тоже покрывает все пары.

## 3. Поиск минимума с начальным значением min = 0

Пусть `min` инициализируется значением 0, а не значением `a[0]`:

```java
int min = 0;
for (int i = 0; i < n; i++)
    if (a[i] < min)
        min = a[i];
```

**Контрпример:** a = {4, 1, 7, 3, 9}. Ни один элемент не меньше 0, поэтому `min` остаётся 0. Алгоритм вернёт 0, хотя наименьший элемент равен 1.

Ошибка также возникает для любого массива, где все элементы больше 0.

**Исправление:** начинать с первого элемента массива:

```java
int min = a[0];
for (int i = 1; i < n; i++)
    if (a[i] < min)
        min = a[i];
```

Теперь для a = {4, 1, 7, 3, 9} результат 1, что верно.
