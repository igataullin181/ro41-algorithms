# t01 СРСП: перевод секунд в часы, минуты и секунды

Дано целое число секунд (не меньше 0). Программа переводит его в часы, минуты и секунды.

## Файлы

- `algorithm.md` — словесная запись алгоритма и псевдокод.
- `flowchart.png` — схема алгоритма (ГОСТ 19.701-90).
- `Program.cs` — консольная программа на C#.
- `srsp.csproj` — файл проекта.

## Запуск

```
dotnet run
```

Программа просит ввести количество секунд. При некорректном вводе (не число, отрицательное число) выводится сообщение об ошибке, и программа завершается без падения.

## Проверка

| Ввод   | Ожидаемый результат | Результат программы |
|--------|---------------------|---------------------|
| 3725   | 1 ч 2 мин 5 с       | 1 ч 2 мин 5 с         |
| 59     | 0 ч 0 мин 59 с      | 0 ч 0 мин 59 с        |
| 86399  | 23 ч 59 мин 59 с    | 23 ч 59 мин 59 с      |
| 0      | 0 ч 0 мин 0 с       | 0 ч 0 мин 0 с         |
| -5     | Сообщение об ошибке | Сообщение об ошибке   |
| abc    | Сообщение об ошибке | Сообщение об ошибке   |

Столбец «Результат программы» получен расчётом по тем же шагам, что выполняет `Program.cs`. Перед сдачей запустите `dotnet run` для каждого ввода и сверьте вывод в консоли с таблицей.
